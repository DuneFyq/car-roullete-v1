# 🚗 Car Roulette

**Website:** https://dunefyq.github.io/car-roullete-v1/

## 📖 About
Car Roulette is a web-based companion game for Forza Horizon, designed for 3 or more players. The goal is to compete against others and claim first place.. 

## 🛠 Tech Stack
- Vanilla TypeScript
- Vite
- Sass

## 🚀 Installation & Running

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/DuneFyq/car-roullete-v1.git
   cd car-roullete-v1
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build the project for production:
   ```bash
   npm run build
   ```

5. Preview the production build locally:
   ```bash
   npm run preview
   ```
